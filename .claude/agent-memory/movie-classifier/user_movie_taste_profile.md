視聴済み464件から読み取れる嗜好（2026-08-16時点）:

- **中心はヨーロッパ・アート系**。フランス映画（ダルデンヌ兄弟、ヴァルダ、オゾン）、イラン映画（キアロスタミ、ファルハディ、パナヒ）、フィンランドのカウリスマキ作品を網羅的に観ている。中華圏（チャン・イーモウ、ホウ・シャオシェン、ウォン・カーウァイ）も厚い。
- **ホラーは量が多い（67件）が、志向は作家性寄り**。ダリオ・アルジェント／ルチオ・フルチ等のイタリアン・ホラーを系統的に、ティ・ウェスト『X』『Pearl』、A24系、韓国ホラー（『哭声』『グエムル』）を高く評価。ジャンプスケア主体の量産ホラーには低スコアを付ける傾向。
- **満点(5.0)を付けた作品**は感情的カタルシスの強い作品に集中（『最強のふたり』『シング・ストリート』『リトル・ダンサー』『RRR』『シティ・オブ・ゴッド』『もののけ姫』）。
- 5.0満点は珍しくなく、**スコア分布は全体的に高め**。4.0/5.0（=8.0/10）を「高評価」の実用的な足切りにすると選出しやすい。

**活かし方:** ジャンル選出時は、同じジャンル内でも作家性・国際性のある作品を優先して上位に置くと刺さりやすい。ハリウッド大作は観ているが評価は中庸なので、企画の主役には据えない。
