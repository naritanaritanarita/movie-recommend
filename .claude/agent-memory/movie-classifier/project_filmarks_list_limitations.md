`output/filmarks/watched_movies.md` は「タイトル / スコア / ジャンル / 公開年 / URL」の5列のみ。**製作国・監督・原題の情報は存在しない。**

**なぜ:** filmarks-fetcher がFilmarksの一覧HTMLから抽出できる範囲がこの5項目に限られるため。結果として「北欧ホラー」「フランス映画」のような国・地域軸の依頼は、すべてモデル側の映画知識で製作国を推定するしかない。

**適用方法:**
- 国・地域軸の選出依頼では、各作品に「なぜその国の作品と判定したか（製作会社・監督の国籍）」を必ず明記する
- 邦題から原題を特定できないエントリは ⚠️ を付けて一覧化し、取りこぼしの可能性を開示する
- リメイクとオリジナルが同名の場合（例: 『胸騒ぎ』2022デンマーク版 vs 2024ハリウッド版）は公開年列で判定し、どちらを仮定したか明記する
- スコアはFilmarksの**個人評価 0.5〜5.0**。しきい値判定時は必ず ×2 で10点満点に正規化する
