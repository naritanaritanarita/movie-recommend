選出条件に合う作品が指定本数（例: 5本）に満たない場合、**条件外の作品で埋めてはいけない**。見つかった件数をそのまま報告し、リスト内に実在する作品名を挙げた具体的な代替案（範囲を広げる方向性）を併記する。

**なぜ:** ユーザーが「北欧ホラー5選」依頼時に明示的に指示。水増しされたリストはYouTube台本の信頼性を損なうため、正直な件数報告を優先したい。

**適用場面:** ニッチな条件（製作国×ジャンル、特定監督、特定年代など）での選出依頼すべて。母集団の全件表と、判定できなかったエントリの ⚠️ 明示もセットで求められる。
