## 確認済みの好み

- **トーン**: カジュアルな話し言葉を好む。書き言葉NG。
- **ネタバレ方針**: 最小限に抑えることを明示的に要求。あらすじは「雰囲気と見どころ」にとどめる。
- **映画紹介の構成**: 各映画に「見どころ」と「怖さのポイント」の両方を含めることを要求。
- **タイトル案の数**: 3つ以上（実際には7案を提供して好評）。
- **エンディング**: チャンネル登録・高評価への誘導を必ず含める。
- **テロップ指示**: 角括弧で演出指示を明記することを好む（[テロップ: 〇〇] 形式）。
- **BGM指示**: 各セクション冒頭にBGM変化の指示を入れる。

## ジャンル傾向

- ホラー映画が好み（スコア5.0多数）
- 幅広い年代（1976〜2024年）をカバーする選出を行う
- ボディホラー、ゴシックホラー、SFホラー、ゲーム原作ホラーなど多様なサブジャンルに精通

## セッション履歴

### 2026-05-10 セッション1（ホラー5選）
- ホラー5選の台本を依頼
- 確定映画リストを自分で用意して提供（movie-classifierに依存しない直接依頼）
- output/drafts/ に保存することを要求

### 2026-05-10 セッション2（ホラー3選）
- テーマ「サブスクで今すぐ観れるホラー映画おすすめ3選」
- タイトル案は5案を明示的に要求（前回は7案を提供、今回は3〜5案の指定あり）
- 各映画の紹介構成として「見どころ」と「こんな人に向いてる」の流れを明示指定
- [SE]・[画面テキスト] 形式の演出指示を要求（前回の [テロップ] 形式と同じ好み）
- 動画尺の目安を明示（5〜7分 / 1600〜2200字）
- ネタバレしないことを改めて明示
- カジュアルトーンを「友達に映画を勧めるような感じ」と具体的に指定
