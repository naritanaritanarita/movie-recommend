## 確認済みの好み

- **トーン**: カジュアルな話し言葉を好む。書き言葉NG。ただしアート系・作家性の強い作品では「軽すぎず作品の凄みが伝わる」バランスを要求する（2026-08-16）。
- **ネタバレ方針**: 最小限に抑えることを明示的に要求。あらすじは「雰囲気と見どころ」にとどめる。Wikipediaのあらすじは結末まで書かれているので導入部のみ使うよう指示される。
- **映画紹介の内容**: 各映画に「あらすじ」「見どころ」「怖さのポイント」「こんな人におすすめ」の4要素を含める。ただしこれは**内容の要件であって構成の型ではない**。ラベル小見出しで区切らず、繋ぎの発話に溶かし込むこと（[[feedback-script-notation]] 参照）。
- **「〇〇選」形式**: 全項目を同じ順序で書かない。作品ごとに入り方を変える（監督から／設定から／テンション転換から／警告から／映像から）。作品間には前後を関連づける繋ぎの発話を必ず置く。
- **タイトル案の数**: 3つ以上（7案が最も好評）。
- **エンディング**: チャンネル登録・高評価への誘導を必ず含める。
- **テロップ指示**: 角括弧で演出指示を明記（[テロップ: 〇〇] / [SE] / [画面テキスト] / [BGM]）。
- **BGM指示**: 各セクション冒頭にBGM変化の指示を入れる。
- **スコア表記**: 5点満点の個人評価であることを視聴者に必ず伝える。10点満点との混同を明確に嫌う（2026-08-16に明示指定）。

## ジャンル傾向

- ホラー映画が好み（スコア5.0多数）
- 幅広い年代（1976〜2024年）をカバーする選出を行う
- ボディホラー、ゴシックホラー、SFホラー、ゲーム原作ホラー、フォークホラー、アート系ホラーなど多様なサブジャンルに精通
- ラース・フォン・トリアー、ヨアキム・トリアー、アリ・アッバシなど作家性の強い監督作を高く評価する傾向

## 効果的だった構成パターン

- **期待値調整パート**（2026-08-16で確立）: 紹介作品が視聴者の一般的な期待とズレる場合、冒頭1分以内に「この動画はこういう内容ではない」と明示するセクションを置く。離脱率対策としてタイトル・サムネにも同じ機能を持たせる。
- **ジャンル定義パート**: 「〇〇ホラーとは何が違うのか」を本編前に1分で解説すると、以降の各作品紹介の説得力が上がる。ハリウッド作品との対比軸が有効。
- **重い題材の注意喚起**: 冒頭の全体警告＋該当作品の章頭で個別警告の二段構え。概要欄にも注意書きを記載し、編集メモで「残酷描写をサムネ・本編映像に使わない」（収益化リスク回避）を添える。
- **順位付け**: 観やすい順（＝低スコア順）に並べ、最高評価作を最後に置く構成が締まる。

## セッション履歴

### 2026-05-10 セッション1（ホラー5選）
- ホラー5選の台本を依頼
- 確定映画リストを自分で用意して提供（movie-classifierに依存しない直接依頼）
- output/drafts/ に保存することを要求

### 2026-05-10 セッション2（ホラー3選）
- テーマ「サブスクで今すぐ観れるホラー映画おすすめ3選」
- タイトル案は5案を明示的に要求
- 各映画の紹介構成として「見どころ」と「こんな人に向いてる」の流れを明示指定
- [SE]・[画面テキスト] 形式の演出指示を要求
- 動画尺の目安を明示（5〜7分 / 1600〜2200字）
- カジュアルトーンを「友達に映画を勧めるような感じ」と具体的に指定

### 2026-08-16 セッション3（北欧ホラー5選）
- テーマ「北欧ホラー おすすめ5選」／確定5本を自分で提供（movie-classifier出力を参照させる形）
- 選出作品が絶叫系ホラーではないアート系だったため、**視聴者の期待値調整を台本に組み込むことを明示要求**
- 重い題材（連続殺人・嬰児殺人）への注意喚起を台本に含めるよう要求
- スコアが5点満点である旨を視聴者に伝えるよう明示要求
