台本ファイルを保存したら、必ず次を実行して合格を確認してから報告する。

`python3 .claude/skills/filmarks-to-youtube/check_script.py <台本ファイルの絶対パス>`

exit code 0 が合格。1 なら違反行が行番号付きで出るので、繋ぎの発話に書き換えて再実行する。検査範囲は `## 動画台本` から `## 制作メモ` の直前まで（絵文字の有無は問わない）。

**なぜ:** 2026-08-16、記事構造の台本を出して差し戻されたときに、機械チェックとセットで運用するよう指示された。合格結果を報告に含めることも求められている。

**適用場面:** 台本を書いた／直したすべての場合。報告前の最終ステップとして固定。

**尺の換算レート:** 日本語ナレーションは **250〜350字/分**（カジュアルな語りなら300字/分で計算するとよい）。リンターも同じレートで推定尺を出すので、表示値をそのまま台本冒頭とセクション時刻に使ってよい。

英語の 150〜200 words/min をそのまま文字数に当てはめると尺が倍近く過大に出る。2026-08-16時点ではリンターとエージェント定義の両方がこの誤ったレートを使っており、5,539字を「27〜36分」（実際は約18分半）と表示していた。どちらも修正済み。
