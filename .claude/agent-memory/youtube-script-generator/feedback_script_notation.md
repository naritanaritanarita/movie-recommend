type: feedback

台本本文には、`### 【セクション名】` 見出しと角括弧の演出指示（`[BGM: …]` `[テロップ: …]` `[SE: …]` `[画面: …]` `[カット]`）以外、演者の口から出る言葉しか書かない。

具体的に禁止されるもの:
`**【あらすじ】**` `**【見どころ】**` `**【怖さのポイント】**` `**【こんな人におすすめ】**` のようなラベル小見出し、箇条書き（`-` `*` `1.`）、`**太字**` 強調、表組み。

**なぜ:** 2026-08-16の北欧ホラー5選で、文体は話し言葉なのに構造がブログ記事のままの台本を出し、「台本になっていない」と差し戻された。理由は3つ挙げられた。①ラベルは演者が読み上げられず画面にも出ない、②ラベルで分断されるとブロック間を繋ぐ発話が消える（台本ではそこが最重要）、③太字は記事の強調記法。文体が話し言葉でも構造がこうなっていれば失格、という判断基準。

**適用場面:** 台本本文を書くとき常時。情報を整理したくなったら小見出しではなく「区切りの役目をする発話」を書く。「あらすじだけ先に言っておきますね」「で、ここが面白いんですけど」「で、ここからが本題なんですけど」「あと、これはハッキリ言っておきますね」など。制作メモ・タイトル案セクションでは通常のMarkdown記法を使ってよい（リンターの検査範囲外）。
